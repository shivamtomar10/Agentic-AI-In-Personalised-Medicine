# Curated offline knowledge base (prototype scale)

`evidence_corpus.jsonl` entries are **author-written paraphrases** of well-known guidelines/labels
(`verbatim: false`). They exist so the pipeline can retrieve, cite and verify offline and reproducibly.
**Before quoting any of them in the dissertation, verify against the cited source** (URLs point to the
publisher landing pages; dates are publication/revision approximations). `drug_classes.yaml` is a small
hand-built table, not DDInter/RxNorm. See `docs/limitations.md`.
